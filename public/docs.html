Dokumentasi API

Base URL: https://DOMAIN. Semua request dan respons berformat JSON.

Autentikasi

Setiap akun punya API key sendiri, bisa dilihat dan dibuat ulang di dashboard tab API. Kirim lewat header:

x-api-key: KEY_KAMU
Panggil API dari server kamu, jangan dari browser atau aplikasi publik. API key hanya bisa membuat dan mengecek transaksi. Tarik saldo dan pengaturan akun hanya lewat dashboard.
GEThttps://DOMAIN/api/me
curl https://DOMAIN/api/me -H "x-api-key: KEY_KAMU"
# {"username":"budi","role":"user","saldo":120000}

Buat transaksi QRIS

POSThttps://DOMAIN/api/pay/create
FieldTipeKeterangan
amountintegerWajib. Nominal rupiah, 1.000 sampai 10.000.000.
channelstringOpsional. qris (default) atau qrisfast.
referencestringOpsional. ID pesanan milikmu (maks 64 karakter), ikut dikembalikan di respons.
Biaya: QRIS 0,1% + Rp 100 (saldo cair H+1) dan QRIS Fast 0,7% + Rp 250 (saldo langsung bisa ditarik). Pilih lewat parameter channel. Siapa yang menanggung diatur di dashboard menu Pengaturan > Biaya QRIS, bukan lewat request.
curl -X POST https://DOMAIN/api/pay/create \
  -H "x-api-key: KEY_KAMU" -H "Content-Type: application/json" \
  -d '{"amount":50000,"reference":"ORDER-1"}'
{ "id": "3F9A1C7E52B0D4A8", "reference": "ORDER-1", "amount": 50000, "fee": 600, "fee_by": "buyer",
  "total": 50600, "net": 50000, "status": "pending",
  "pay_url": "https://DOMAIN/pay/3F9A1C7E52B0D4A8",
  "qr_url": "https://DOMAIN/pay/3F9A1C7E52B0D4A8/qr",
  "expiry": "2026-10-02 14:45:00", "createdAt": "2026-10-02T07:30:00.000Z" }
FieldKeterangan
idID transaksi. Dipakai untuk cek status dan batal. Simpan di database kamu.
fee, fee_byBiaya QRIS (rupiah) dan penanggungnya: buyer atau merchant.
totalYang harus dibayar pembeli. Kalau fee_by = buyer, nilainya amount + fee. Kalau merchant, sama dengan amount. Tampilkan nilai ini ke pembeli.
netYang masuk ke saldomu setelah dibayar. buyer: sama dengan amount. merchant: amount dikurangi fee.
pay_urlHalaman bayar. Kirim ke pembeli lewat WhatsApp, email, atau chat. Statusnya berubah otomatis saat dibayar.
qr_urlGambar QR, bisa dipasang langsung di <img>. Bisa null, pakai pay_url saja.
expiryBatas waktu pembayaran.

Cek status transaksi

GEThttps://DOMAIN/api/pay/status?id=ID
POSThttps://DOMAIN/api/pay/status  body: {"id":"ID"}
curl "https://DOMAIN/api/pay/status?id=3F9A1C7E52B0D4A8" -H "x-api-key: KEY_KAMU"

Responsnya sama seperti saat membuat transaksi, dengan status terbaru.

statusArti
pendingBelum dibayar. Cek lagi tiap 3 sampai 5 detik.
settlementSudah dibayar. Saldo akunmu bertambah sebesar net, sekali saja.
expireLewat batas waktu.
cancelDibatalkan.

Batalkan dan daftar

POSThttps://DOMAIN/api/pay/cancel  body: {"id":"ID"}, hanya yang masih pending
GEThttps://DOMAIN/api/pay/list  50 transaksi terakhir

Tarik saldo

Penarikan dilakukan di dashboard tab Tarik saldo: pilih metode, isi tujuan dan nominal. Fee dan batas ditampilkan sebelum diajukan. Admin memproses transfer, dan kalau ditolak saldo kembali otomatis.

Error

Bentuknya {"error":"pesan"} dengan kode HTTP:

KodeArti
400Input tidak valid, misalnya nominal di luar batas.
401API key tidak ada atau tidak valid.
403Endpoint ini hanya bisa lewat dashboard.
404Transaksi tidak ditemukan.
429Terlalu banyak request (batas buat transaksi 30 per menit).
502Layanan pembayaran sedang bermasalah, coba lagi sebentar.
